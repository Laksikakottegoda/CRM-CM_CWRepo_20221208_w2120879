# CRM-CM_CWRepo_20221208_w2120879



This coursework focuses on analysing and segmenting S&P 500 stocks using historical financial data from 2021 to 2024. Python and Google Colab are used to calculate weekly returns, market beta, and adapted Recency, Frequency, and Monetary (RFM) measures based on trading activity.

The project applies K-means and Agglomerative Clustering to group stocks with similar characteristics and compare the results. It also examines the impact of different features on clustering and explores how Business Intelligence techniques can support investment analysis and data-driven decision-making.
